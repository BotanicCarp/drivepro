DRIVEPRO V7 — КАЛЕНДАРЬ

1. Остановите старый сервер Ctrl+C.
2. Распакуйте архив в новую папку.
3. В Supabase SQL Editor выполните schema-v7.sql.
4. Запустите START-DRIVEPRO.bat.
5. Откройте http://localhost:5500/i/ivan-petrov

Новый график:
07:00–19:00
обед 12:00–13:00
Пн–Сб работа, Вс выходной.

Календарь:
- слева месяц;
- зелёная точка = есть свободные часы;
- справа неделя;
- зелёные слоты = свободно;
- серые = занято;
- красные = обед;
- прошедшие часы недоступны;
- клик по свободному часу создаёт booking.

Также исправлена `infinite recursion detected in policy for relation "bookings"`:
политика больше не делает SELECT из самой таблицы bookings; двойное бронирование защищает partial unique index.

Тариф:
курсант — 0 ₸;
инструктор — 15 000 ₸ подключение + 2 990 ₸/месяц.

Отзывы:
- курсант ставит оценку 1–5;
- пишет отзыв до 500 символов;
- может изменить свой отзыв;
- один отзыв на одного инструктора;
- средняя оценка и отзывы отображаются в расписании.

Многослотовая запись:
- при нажатии на свободное время появляется окно выбора типа занятия и количества уроков;
- 1 урок = 45 минут (1 академический час);
- 2 урока = 2 последовательных часа;
- для автодрома система автоматически требует 2 урока;
- перед автодромом показывается предупреждение;
- система проверяет оба последовательных часа;
- нельзя пересечь обед 12:00–13:00 или закончить позже 19:00;
- два часа одной записи объединяются общим booking_group_id.

Главная страница курсанта:
- блок «Ближайшее занятие» теперь автоматически показывает ближайшую подтверждённую запись;
- отображаются дата, время, инструктор, автомобиль и количество академических часов;
- если записей нет, остаются кнопки для перехода к расписанию.

V12 — кабинет инструктора: обзор, ближайшее занятие, статистика, расписание 45 минут, закрытие слотов, курсанты, занятия, отзывы, подписка и профиль.


V13 — корректная модель академических часов

ВАЖНО: перед использованием новой версии один раз выполните migration-v13.sql в Supabase SQL Editor.

Изменения:
- 1 академический час = 45 минут;
- 2 академических часа = 90 минут;
- одна запись хранится одной строкой bookings;
- добавлено поле ends_at;
- старые две строки одной групповой записи объединяются в одну;
- расписание курсанта и инструктора работает по 45-минутным слотам;
- 90-минутная запись занимает два последовательных 45-минутных слота;
- автодром автоматически фиксируется на 90 минут;
- запись не может пересекать обед или рабочий график;
- Supabase дополнительно запрещает пересечение подтверждённых записей одного инструктора через exclusion constraint;
- в кабинете инструктора отображается реальный диапазон, например 07:00–08:30;
- отображается ФИО и телефон курсанта, если они доступны;
- исправлен вызов ближайшего занятия в кабинете курсанта.
